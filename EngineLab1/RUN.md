## Сборка и запуск

Проект предназначен для Windows. Для сборки нужны инструменты Visual Studio 2022 с установленным компонентом «Разработка классических приложений на C++». В качестве редактора можно использовать VS Code.

Конфигурация сборки: **Release**, платформа: **x64**.

### Зависимости

- raylib 5.5;
- Assimp;
- GLM;
- stb;
- nlohmann/json;
- Tracy 0.12.2.

Пути к библиотекам в настройках проекта должны соответствовать их расположению на компьютере. Путь к `TracyClient.cpp` задаётся в `Directory.Build.targets`.

### Сборка проекта

Откройте PowerShell в корневой папке проекта, где находится `EngineLab1.sln`, и выполните:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" ".\EngineLab1.sln" /t:Build /p:Configuration=Release /p:Platform=x64 /m /v:minimal
```

Если Visual Studio установлена в другую папку или используется другая редакция, замените путь к `MSBuild.exe`.

После успешной сборки исполняемый файл находится в `x64\Release\EngineLab1.exe`.

### Запуск приложения

Из корневой папки проекта выполните:

```powershell
Set-Location .\EngineLab1
& ..\x64\Release\EngineLab1.exe
```

Рабочая папка при запуске должна содержать каталог `Assets`: ресурсы загружаются по относительным путям.

После закрытия приложения вернуться в корневую папку можно командой:

```powershell
Set-Location ..
```

При использовании настроенной конфигурации VS Code можно выбрать **«Запуск → Запустить без отладки»** или нажать **Ctrl+F5**.

### Управление

После открытия сцены доступны следующие клавиши:

| Клавиша | Действие |
|---|---|
| B | Переключение обычной и тестовой сцены |
| P | Переключение последовательной и параллельной подготовки матриц |
| R | Запуск измерения на загруженной тестовой сцене |
| L | Переключение синхронной и фоновой загрузки ресурсов с перезагрузкой сцены |
| O | Повторная загрузка текущей сцены |

Переключение режимов выполняется после завершения загрузки и вне активного измерения.

Режим загрузки ресурсов и режим подготовки матриц переключаются независимо.

### Измерение производительности

Для сравнения последовательной и параллельной подготовки матриц:

1. Запустите сборку **Release x64**.
2. Откройте тестовую сцену клавишей **B**.
3. Дождитесь завершения загрузки.
4. Выберите режим подготовки матриц клавишей **P**.
5. Нажмите **R**.
6. Дождитесь сообщения `Benchmark saved` в журнале.
7. Выполните не менее трёх измерений для каждого режима в одинаковых условиях.

Измерение включает прогрев около 5 секунд и запись около 10 секунд. Результаты сохраняются в каталог `BenchmarkResults`; точный путь выводится в журнал.

В результатах представлены время кадра и время подготовки матриц: медиана, p95 и p99. Ускорение подготовки матриц не означает такое же ускорение всего кадра.

Для сравнения загрузки ресурсов используйте **L** для выбора режима и **O** для повторной загрузки текущей сцены.

### Профилирование в Tracy

В проект подключён профилировщик **Tracy 0.12.2**. Он позволяет просматривать выполнение задач в основном и рабочих потоках, а также длительность отдельных участков кода.

Для просмотра сохранённых файлов `.tracy` используйте совместимую версию Tracy Viewer — **0.12.2**.

Для обычного запуска приложения открывать Tracy Viewer не требуется.
